!!! warning "流量不够了怎么办？"
    流量不够时，通常有 3 种处理方式：购买流量重置包、升级套餐或原套餐续费。  
    不同方式对流量、有效期和套餐价值的影响不同，建议先查看 [流量不够了怎么办](faq/traffic.md) 页面的详细说明，再选择最适合自己的方案。

!!! info "倍率节点说明"
    部分高端节点可能是 `2 倍率` 或 `10 倍率`，表示流量会按对应倍数扣除。  
    如果你流量有限，建议优先选择低倍率节点，并尽量关闭客户端的自动选节点或故障转移功能。
